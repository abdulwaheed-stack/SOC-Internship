# Intermediate-Level Cybersecurity Projects

## Level 2 — Beyond the Fundamentals

Welcome to Level 2 of my cybersecurity project portfolio.

The Intermediate level represents the transition from foundational cybersecurity concepts to more challenging, practical technical work.

While beginner projects focus on understanding essential tools, analysing basic security events, and establishing foundational security environments, this level introduces more complex problem-solving, independent analysis, and industry-relevant security methodologies.

## Level 2 Objectives

- Develop stronger technical and analytical skills.
- Work with more complex security tools and datasets.
- Explore practical cybersecurity scenarios.
- Improve investigation and problem-solving capabilities.
- Apply industry frameworks and methodologies.
- Produce structured, evidence-based technical documentation.

## Project Approach

Projects at this level are selected to provide additional technical depth and practical exposure beyond foundational exercises.

Each project focuses on a defined objective, with emphasis on understanding the underlying concepts, applying appropriate tools, interpreting results, and documenting outcomes accurately.
